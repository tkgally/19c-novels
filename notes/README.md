# Working notes

Index of the project’s working documentation:

- `preferences.md` — Tom’s instructions and decisions (committed before acting on them)
- `workflow.md` — the end-to-end digitization, multi-pass verification, audit, and publication pipeline
- `selection.md` — eligibility conditions, vetting sources, and how novels are chosen
- `style.md` — editorial rules for the text, multi-volume structure, reading editions, and site prose
- `page-markup.md` — plain-text page markup (`pages/pNNNN.txt`)
- `book-json.md` — `book.json`, `source.json`, and `log.md` format
- `site.md` — how the website is organized and grows
- `lessons.md` — standing lessons organized by trigger (pruned once enforced by a tool)
- `metrics.md` — version-by-version record of audits, judge spots, corrections, and preflight checks
- `sessions.md` — session log (start/end time, context meter, work completed)
- `errata.md` — errors reported by Tom or readers and their follow-through
- `improvement.md` — continuous evaluation and periodic review procedure
