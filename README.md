# Forgotten Novels

Lesser-known and forgotten novels written in English and published between 1700 and 1914, transcribed from library scans at the Internet Archive and published as web pages, EPUB, ODT, and JSON.

Site: https://tkgally.github.io/19c-novels/

The novels are chosen, transcribed, and checked by Gemini models, inspired by Tom Gally’s 2021 Internet Archive blog post, [“Forgotten Novels of the 19th Century”](https://blog.archive.org/2021/07/14/forgotten-novels-of-the-19th-century/). Multi-volume novels are published digitally as single volumes. The method is in `notes/workflow.md` and is described for readers on the site’s About page. Errors can be reported in the issues.

- `books/` — the source of each published novel (page text, metadata, illustrations)
- `tools/`, `prompts/`, `tests/` — the pipeline
- `site/` — stylesheets and the site’s own pages
- `notes/` — working notes
- `GEMINI.md`, `RESUME.md` — instructions for the sessions that do the work
